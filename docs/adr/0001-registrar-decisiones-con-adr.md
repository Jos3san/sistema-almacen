# ADR-0001: Registrar las decisiones de arquitectura con ADRs

- **Estado:** Aceptado
- **Fecha:** 2026-10-27

## Contexto
El proyecto es también un portafolio y una herramienta de aprendizaje. Las decisiones se toman en conversaciones y se pierden.

## Decisión
Cada decisión de arquitectura o de proceso relevante se registra como un ADR en `docs/adr/`, numerado y usando `0000-plantilla.md`. Un ADR aceptado no se edita: se reemplaza por otro nuevo.

## Consecuencias
- Positivas: historial de por qué el sistema es como es; material para el portafolio.
- Negativas: un poco de tiempo extra por decisión.
